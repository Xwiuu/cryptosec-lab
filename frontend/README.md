# Frontend (Opcional)

Interfaces para interagir com a blockchain local.

## Modulos

```
wallet-ui/         - Interface de wallet
dex-ui/            - DEX interface
dao-ui/            - DAO governance interface
audit-dashboard/   - Dashboard de auditoria
```

## Stack Planejada

- Next.js
- TypeScript
- Tailwind CSS
- viem / ethers.js
- wagmi

## Setup

```bash
cd frontend/[module]
npm install
npm run dev
```
