# GitHub Setup

Use GitHub native checks for automated repository review.

Recommended checks:

- CodeQL workflow.
- Dependabot configuration.
- Secret scanning, if available.
- Repository security policy.

Manual Kali findings are tracked as GitHub Issues and in `docs/security/VULNERABILITY_REGISTER.md`.

- `docs/security/SECURITY_SPRINT_01.md`
- `docs/security/PENTEST_REPORT_2026-06-20.md`
- `docs/security/RETEST_REPORT_2026-06-20.md`
