# Ethical Use Agreement

By downloading, installing, or interacting with the CryptoSec Lab repository, you agree to the following terms:

1. **Authorized Environments**: You will only execute the exploits, simulations, and vulnerable contracts inside local, isolated virtual networks (e.g., Anvil, Ganache, hardhat, or local rust testbeds).
2. **No Malicious Targeting**: You will not use the templates, scripts, or exploit techniques documented here to launch attacks against third-party systems, live contracts, or real user assets.
3. **Academic Integrity**: You will use this laboratory to learn security patterns, build mitigations, and improve audit checklists.
4. **Responsible Disclosure**: If you discover vulnerabilities in public Web3 protocols during your security audits, you will follow responsible disclosure guidelines by notifying the core teams privately before publishing details.
