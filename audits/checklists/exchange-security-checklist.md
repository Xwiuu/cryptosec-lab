# Exchange Security Checklist

## Custody
- [ ] Hot wallet limits
- [ ] Cold wallet majority of funds
- [ ] Multi-sig for cold wallet
- [ ] Withdrawal approval workflow
- [ ] Address whitelisting

## Withdrawals
- [ ] Manual approval for large withdrawals
- [ ] Rate limiting
- [ ] 2FA required
- [ ] Email confirmation
- [ ] Withdrawal amount limits

## Internal Ledger
- [ ] Real-time reconciliation
- [ ] Audit trail for all transactions
- [ ] No negative balances
- [ ] Snapshot for proof-of-reserves

## API Security
- [ ] API key permissions
- [ ] Rate limiting
- [ ] IP whitelisting
- [ ] Request signing
- [ ] No sensitive data in responses

## Admin Panel
- [ ] 2FA required
- [ ] IP restrictions
- [ ] Session management
- [ ] Action logging
- [ ] Multiple approval for sensitive actions

## Proof of Reserves
- [ ] Regular merkle tree proofs
- [ ] Third-party auditor
- [ ] Public verification tool
- [ ] Liabilities matching assets
