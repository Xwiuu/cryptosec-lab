# Screenshots Directory

This directory is designated for high-resolution screenshots of the **CryptoSec Lab Visual Simulator** and the **Premium Admin Console**.

## Planned Screenshot Assets

1. `admin-dashboard-overview.png`: Consolidate B2B metrics, active client risk scores, and recent lab simulations.
2. `admin-findings-board.png`: The Kanban board detailing open, in-fix, and retest-passed vulnerabilities.
3. `admin-scans-logs.png`: Historical log output of static analysis scanner runs.
4. `lab-amm-sandwich.png`: Slippage and sandwich attack playground in action.

Please capture screenshots when running the web application locally via `npm run dev` and save them under this directory before publishing.
